# 마도아카데미 지휘관 원화

[전체 캐릭터 자료](README.md) · [기존 지휘관 설정](../CHARACTERS.md#3-지휘관)

성인 대상 게임의 지휘관 세 명을 전원 성인 여성으로 디자인한다. 하르텐은 슬렌더, 이세라와 녹스는 볼륨감 있는 체형이라는 사용자 지정 방향을 따른다. 기존 유닛 원화와 같은 선화·셀 명암·재질 표현을 사용하며, 어깨·쇄골·허리·허벅지가 드러나는 불투명 판타지 의상으로 통일한다.

아래 나이와 외형은 아카데미 스킨용 설정이다. 기존 원전의 나이·세계관과 구분하며, 게임 데이터 ID·능력·수치를 그대로 대응시킨다.

| 번호·설정 | 지휘관 / 데이터 ID | 아카데미 포지션 | 나이 | 키 | B/W/H (cm) | 체형 | 대표 외형 |
|---|---|---|---|---|---|---|---|
| [C01](C01/README.md) | 하르텐 볼크 / `cmd_harten` | 강철의 선도부장 | 28세 | 176 cm | 78/58/84 | 작은 가슴·좁은 골반·긴 팔다리의 슬렌더 | 흑발 올림머리·푸른 눈·남색 군복·각진 방패 |
| [C02](C02/README.md) | 이세라 칸델 / `cmd_isera` | 폭발물 학부의 문제아 수석 | 24세 | 168 cm | 98/64/101 | 풍만한 가슴·골반·탄력 있는 허벅지의 곡선형 | 붉은 장발·호박색 눈·열린 실험 가운·화염 지팡이 |
| [C03](C03/README.md) | 녹스 / `cmd_nox` | 금서 거래상 | 27세 | 174 cm | 102/66/104 | 풍만한 가슴·넓은 골반·긴 다리의 성숙한 곡선형 | 보라빛 흑발·자수정 눈·검보라 연미복·계약 장부 |

## 생성 완료 파일

세 명 모두 전신·초상화·전투용 SD를 생성해 저장했다. 선택된 PNG는 총 9장이고, 개별 설정에는 나이·키·쓰리사이즈·머리색·의상·장비·성격을 정리했다.

| 지휘관 | 전신 | 초상화 | 전투용 SD |
|---|---|---|---|
| 하르텐 | [illustration.png](C01/illustration.png) | [portrait.png](C01/portrait.png) | [sd.png](C01/sd.png) |
| 이세라 | [illustration.png](C02/illustration.png) | [portrait.png](C02/portrait.png) | [sd.png](C02/sd.png) |
| 녹스 | [illustration.png](C03/illustration.png) | [portrait.png](C03/portrait.png) | [sd.png](C03/sd.png) |

내장 이미지 생성 도구로 제작했다. 최종 선택 파일의 크기·해시·사용 프롬프트는 [지휘관 에셋 목록](commander-asset-manifest.json)에 기록한다. 번호가 붙은 이전 버전은 비교용이며 게임용 대표 파일은 위의 세 가지 이름이다.

## 저장 구조

```text
characters/
  C01/                       # 하르텐
    README.md                # 개별 설정
    illustration.png         # 대표 전신
    portrait.png             # 초상화
    sd.png                   # 전투용 SD
    illustration.prompt.md   # 전신 생성 프롬프트
    portrait.prompt.md       # 초상화 생성 프롬프트
    sd.prompt.md             # SD 생성 프롬프트
  C02/                       # 이세라, 같은 구성
  C03/                       # 녹스, 같은 구성
  commander-asset-manifest.json
```

## 공통 제작 기준

| 항목 | 기준 |
|---|---|
| 인물 | 전원 성인 여성. 체형 차이는 전신·초상화·SD 모두 유지한다. |
| 화풍 | 기존 U01~U30과 같은 애니메이션풍 선화·정돈된 셀 명암·금속과 천의 재질 표현. |
| 전신 | 세로 2:3, 약 7~8등신, 눈높이의 정면에 가까운 3/4 시점. 머리 장식·발끝·주요 장비를 프레임 안에 넣는다. |
| 초상화 | 정사각형, 머리와 어깨·상반신 중심. 전신의 얼굴·의상·체형을 유지한다. |
| SD | 정사각형, 약 3등신의 성인 캐릭터 게임 토큰. 머리 모양·소속색·대표 장비·체형 차이를 단순화해 유지한다. |
| 의상 | 성인 게임 지향의 어깨 트임·크롭 상의·짧은 치마·높은 옆트임. 주요 의복은 불투명하게 유지한다. |
| 배경 | 투명 배경 PNG. 문구·테두리·카드 UI·워터마크를 넣지 않는다. |
| 해부 구조 | 팔과 손은 각각 두 개. 각 손의 소품과 팔의 연결이 명확해야 한다. |

## 기존 유닛과의 구분

- 하르텐은 리네의 큰 리본·밤색 단발과 아델의 은발 포니테일을 쓰지 않는다. 흑발 올림머리와 가늘고 곧은 실루엣이 중심이다.
- 이세라는 피아의 짧은 양 갈래 머리를 쓰지 않는다. 긴 붉은 머리와 풍만한 성인 체형, 큰 화염 지팡이로 지휘관의 존재감을 만든다.
- 녹스는 에레브의 연구회장 포지션과 구분되는 거래상이다. 계약 장부와 거래 제스처, 검보라 연미복을 중심으로 한다.
