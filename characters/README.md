## 폴더 구조

```text
characters/
  README.md              # 목록·공통 제작 기준
  U01/
    README.md            # 리네 설정
    illustration.png     # 대표 전신 일러스트 — 2차 버전 저장 완료
    portrait.png         # 초상화
    sd.png               # 전투용 SD
  U02/
    README.md            # 카렌 설정
  ...
  U30/
    README.md            # 에델 설정
```

폴더명은 기존 설정의 U01~U30 번호를 유지한다. 30명 모두 `README.md`에 개별 설정이 있고, 같은 파일명으로 전신·초상화·전투용 SD를 보관한다. 대표 이미지는 총 90개이며, 생성에 사용한 프롬프트는 각 폴더의 `*.prompt.md`에 기록한다. 제작·검수 상태는 진행표와 검증 기록을 기준으로 확인한다.

## 공통 세계관·캐릭터 방향

- 성인 대상 게임을 지향한다. 전원 성인 여성 설정을 유지하고, 어깨·쇄골·허리·허벅지가 드러나는 의상과 몸에 맞는 실루엣을 기본으로 한다. 노출 위치와 의상 형태는 캐릭터의 역할·성격·소속에 따라 차별화한다.

**“학생회가 금지된 의식으로 학교를 봉쇄했다. 남겨진 문제아들과 학원의 오래된 존재들이 교정을 되찾는다.”**

- 유닛 30기 전원 성인 여성 캐릭터로 구성한다. 학원은 성인 대상의 고등 마도교육기관이며, 인간·수인 학생은 모두 20세 이상이다. 정령과 계약 존재도 여성으로 설정하고 성인 여성의 인격·외형·체형으로 디자인한다. 모범생, 불량학생, 연구광, 수인, 인공 정령 등을 섞어 30명의 인상과 실루엣을 구분한다.
- 공통 복식은 남색·아이보리 성인 마도아카데미 제복의 변형과 학원 문장. 크롭 재킷, 오프숄더, 짧은 치마·반바지, 옆트임, 허벅지 스타킹을 조합한다. 갑옷·실험 가운·원예 앞치마는 노출 부위와 대비되는 직업 소품으로 유지한다.
- 전투에서는 SD 캐릭터를 기준으로 머리 모양, 큰 소품 하나, 대표색이 먼저 보이게 한다. 일러스트에서는 표정과 소품의 사연을 더한다.
- 1등급은 친숙한 신입, 2등급은 개성 강한 동아리원, 3등급은 전문 분야의 실력자, 4등급은 학내 유명인, 5등급은 학원의 비밀과 연결된 존재로 잡는다. 등급은 학년과 별개다.
- 같은 유닛의 여러 기는 게임상 복제 배치로 취급한다. 1~3성은 같은 인물이며, 승급 시 장비·마법 문양·이펙트가 발전한다.

## 소속·역할 디자인

기존 기원 네 가지를 아래 소속으로 대응시킨다. 직업은 각 소속 안의 전투 역할로 유지하므로, 원예부에도 수호자·사수·암살자가 함께 존재한다.

| 기존 기원 | 학원 소속 | 대표색·문양 | 캐릭터 방향 |
|---|---|---|---|
| 강철군단 | 규율의 기사학부 | 남색·은색·코발트 / 방패와 교표 | 선도위원, 결투부, 의무실, 마도병기 실습생. 규칙을 지키던 사람들이 학교를 구하려고 교칙을 어긴다. |
| 잿불 | 폭발물 마법학부 | 아이보리·주홍·구리 / 불꽃과 플라스크 | 화염술식, 연금공학, 불꽃 공연. 사고를 많이 쳐 봤기에 재난 속에서도 손이 먼저 움직인다. |
| 심연 | 금서 연구회 | 먹색·보라·청록 / 눈과 잠긴 책 | 도서관의 금지 구역에서 활동하던 비공인 연구회. 저주와 계약을 쓰지만 서로의 대가를 대신 떠안는다. |
| 숲의 맹약 | 정령 원예부 | 크림색·초록·꿀빛 / 잎과 씨앗 | 온실 관리인, 수인 학생, 사역마, 학원 정령. 돌보던 생명들과 함께 교정 밖으로 나선다. |

| 기존 직업 | 학원에서의 역할 | 외형에서 강조할 요소 |
|---|---|---|

| 검투사 | 근접 결투 담당 | 검·건틀릿, 전진 자세, 공격 시 변하는 장비 |
| 사수 | 원거리 사격 담당 | 활·총·발사기, 조준 장치, 탄약 소품 |
| 주술사 | 술식·지원 담당 | 책·지팡이·실험 도구, 떠 있는 마법진 |
| 암살자 | 잠입·기습 담당 | 짧은 무기, 비대칭 복장, 도약과 잔상 |

## 일러스트 공통 제작 기준

| 항목 | 기준 |
|---|---|
| 작화 | 애니메이션풍 2D, 선명한 선화와 셀 명암. 30명에게 같은 선 굵기·명암 단계·채색 밀도를 적용한다. |
| 인물 | 전원 성인 여성. 전신은 약 7~8등신을 기본으로 하며 개인 설정의 키·골격·체형 차이를 반영한다. |
| 기본 전신 | 세로 2:3 비율, 정면에 가까운 3/4 시점, 시점은 눈높이. 머리 장식·발끝·핵심 장비를 프레임 안에 넣는다. |
| 배경 | 기본 전신·초상·SD는 투명 PNG를 기준으로 한다. 배경이 포함된 연출 일러스트는 별도 파일로 보관한다. |
| 작품 지향 | 성인 대상 게임. 성인 여성의 매력과 노출 있는 판타지 의상을 전체 아트 방향으로 삼는다. |
| 복식 | 각 캐릭터 README의 노출 포인트와 복장·신발을 따른다. 오프숄더·크롭 탑·짧은 치마·옆트임으로 변주하고 학원 문장과 소속색을 유지한다. |
| 색상 | 개인 설정의 머리색·눈색 HEX를 기준색으로 사용한다. 인물마다 조명색이 크게 달라지지 않게 한다. |
| 자세 | 개인 설정의 기본 자세를 적용하되 얼굴과 핵심 장비를 알아볼 수 있게 한다. |
| 화면 구성 | 대표 일러스트에는 글자·번호·로고·외곽 UI를 넣지 않는다. |
| SD | 같은 인물·의상·머리색·장비를 유지한다. 소품 수를 줄이고 머리 모양·대표 장비·소속색을 우선한다. |
| 승급 | 1~3성은 같은 인물이다. 머리색과 기본 실루엣을 유지하고 장비 전개·문양·이펙트로 차이를 낸다. |

## 파일·설정 관리

- 각 폴더의 `README.md`는 해당 캐릭터의 작업용 설정이다. 이후 설정을 바꾸면 전체 컨셉 원안의 해당 항목도 함께 갱신한다.
- 대표 전신은 `illustration.png`, 초상화는 `portrait.png`, SD는 `sd.png`로 통일한다.
- 후보 이미지는 `illustration_v01.png`, `illustration_v02.png`처럼 보관하고, 채택본을 대표 파일명으로 저장한다.
- 게임 데이터 ID는 각 설정의 기본 정보에 기록했다. 폴더 번호와 ID의 대응을 유지한다.
- 게임 빌드 시 대표 PNG 3종과 검증 기록을 `dist/characters/`에 포함한다. 배포 후 `characters/U01/illustration.png` 같은 경로로 열 수 있다. 게임 화면의 유닛 렌더러 적용은 별도 작업이다.

## 이미지 검증

`tools/character_assets.py`는 내장 이미지 생성 도구의 결과를 기록하고 검사하는 보조 도구다. Python과 Pillow를 사용하며, 이미지 생성 API를 별도로 호출하지 않는다.

```text
python tools/character_assets.py progress
python tools/character_assets.py audit
```

전체 검증은 90개 대표 PNG의 투명도·화면 비율·해시·중복 여부와 미해결 검수 항목을 확인한다. 원본 이미지와 초상화·SD의 얼굴·복식·장비 일치는 별도로 시각 검수한다.
