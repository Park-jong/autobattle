# 유물 원화

게임의 일반 9종·희귀 8종·보스 11종 유물에 대응하는 이미지 28장입니다.
내장 `image_gen`으로 각각 생성한 투명 배경 원화를 보관하고, 게임에서는 같은 그림의 경량 WebP를 사용합니다.

- `prompts.json`: 공통 아트 지침과 유물별 최종 생성 프롬프트.
- `source/<relic-id>.png`: 생성된 원본. 기존 파일은 다른 그림으로 자동 덮어쓰지 않습니다.
- `asset-manifest.json`: 데이터 ID, 파일 경로, 원본/게임용 크기, SHA-256, 배포 용량.
- `../../public/relics/<relic-id>.webp`: 게임에서 사용하는 최대 384px 이미지. 원화의 구도·종횡비·알파를 유지합니다.

유물 그림은 상점·보상·보유 목록·유물 도감·상세창에서 공통으로 사용합니다.
등급 프레임과 이름·효과 문구는 UI에서 표시하며, 이미지 안에는 글자를 넣지 않았습니다.

원본에서 게임용 이미지를 다시 패키징하려면 저장소 루트에서 실행합니다. Pillow가 필요하며, 이 명령은 이미지 생성 API를 호출하지 않습니다.

```powershell
python tools/relic-assets.py
```
