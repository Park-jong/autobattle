원래 캐릭터의 머리색·눈·개성을 계승하고, 체형은 시티 오퍼레이션 전용 구분을 따른다. 원전의 동물 귀·꼬리·정령 신체는 통신 헤드셋·전술 장식·콜사인으로 재해석하며 실제 신체는 성인 인간 여성이다. 쇄골·어깨·복부·허벅지를 개별 복식 설정에 따라 조금 더 드러낸다. 중간형·폭유형은 의상에 명시한 경우 가슴 윗선을 소폭 드러낸다. 빈유형은 작고 평평한 실루엣, 중간형은 자연스러운 중간 볼륨, 폭유형은 매우 풍만한 실루엣을 유지한다. 유두·가슴 아래·골반은 불투명한 옷으로 가리고 전술 장비와 역할별 개성을 유지한다.

## 성격·배경

현장에서 임시 방호 설비를 세우는 공병. 자신이 만든 장비를 동료보다 먼저 시험한다.

대사: “내가 맡은 구역은 끝까지 지킬게.”

## 전투·카드 연출

**방호 설비** — 구리색 포인트의 경기관총과 정비 팩를 중심으로 기존 유닛·지휘관의 효과를 현대전 연출에 대응시킨다. 사격·피격은 동일한 전투 시간으로 재생하며 코어의 ID·수치·사거리·공격속도·효과는 그대로 연결한다. UI 무기 분류는 `machinegun`이다.

전신은 자연스러운 성인 7~8등신, 초상화는 같은 얼굴·의상의 상반신, SD는 같은 성인 캐릭터를 약 3등신으로 단순화한 전투 토큰이다. SD에서 총구는 화면 오른쪽, 몸통 높이로 향하게 해 사격 이펙트와 연결한다. 칼은 근접 베기, 드론은 어깨 오른쪽의 지원 장치가 공격 주체가 된다. 모든 이미지에서 팔과 손은 각각 두 개다.

## 원화 개정 상태

현재 체형·복식에 맞춘 원화 **3/3종 개정 완료**. 전신·초상화·SD의 개별 상태는 [제작 진행](../PROGRESS.md)을 따른다. 기존 생성 프롬프트는 이전 제작 기록으로 보존하고, 개정 프롬프트는 `*.refinement.prompt.md`에 기록한다.
