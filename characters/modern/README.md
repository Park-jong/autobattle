# 시티 오퍼레이션 — 현대전 스킨

성인 여성 전문 작전요원 30명과 지휘관 3명으로 구성한 추가 선택 스킨. 밝은 도시전 애니풍, 화이트·네이비·시안 UI와 총기·드론 중심 전투를 사용한다. 33명을 빈유형 9명·중간형 11명·폭유형 13명으로 구분한다. 하르텐은 빈유형 슬렌더, 이세라·녹스는 폭유형 성인 체형이다.

## 참고 방향

[소녀전선 2 공식 사이트](https://gf2.haoplay.com/en/)의 현대 전술 장비와 [블루아카이브 공식 사이트](https://bluearchive.nexon.com/)에서 참고한 화사한 도시 애니풍을 독자적인 부대·캐릭터 복장으로 구성했다. 기존 작품의 캐릭터·로고·일러스트는 사용하지 않는다. 모든 인물은 22세 이상 성인 여성이다.

## 체형·복식 개정 기준

- 체형 구분은 `bustType: small`(빈유형), `medium`(중간형), `large`(폭유형)의 3단계로 명시한다. 빈유형은 작고 평평한 가슴, 중간형은 자연스러운 중간 볼륨, 폭유형은 매우 풍만한 가슴으로 실루엣 차이를 분명히 한다. 중간형을 빈유처럼 평평하게 또는 폭유처럼 과장해서 그리지 않는다.
- 가슴 크기와 어깨·골반·근육량은 별개다. 각자의 장신·근력형·유연형·사수 체형을 유지하며 전원을 같은 몸매로 만들지 않는다. B/W/H는 캐릭터 디자인 참고 수치다.
- 노출은 기존 전술복에서 한 단계만 높인다. 열린 네크라인, 어깨 트임, 크롭 밑단, 짧은 전술 하의를 조합해 쇄골·어깨·복부·허벅지를 소폭 드러낸다. 중간형·폭유형의 윗가슴 노출은 개별 의상에 명시한 범위로 제한한다.
- 의복은 불투명하며 유두·가슴 아래·골반을 덮는다. 부대 색, 장비, 성인 전문요원으로서의 자세와 인상을 유지한다.
- 전신·초상화·SD 모두 같은 체형 구분과 의상을 따른다. 현재 설정이 이전 참조 원화와 다르면 체형·복식은 현재 설정을, 얼굴·머리·눈·장비는 캐릭터 정체성을 따른다.

**현재 체형·복식 개정 원화 99/99장 완료.** [제작 진행](PROGRESS.md)에서 캐릭터별 상태를 확인한다. 개정 전 PNG는 버전별로 보존하며, 새 제작 프롬프트는 `*.refinement.prompt.md`에 기록한다.

## 제작·적용 범위

- 캐릭터별 설정 MD, 전신·초상화·SD PNG와 생성 프롬프트: 33명 × 3종 = 99장.
- 원본은 characters/modern/{U01~U30,C01~C03}, 배포용 축소본은 public/skins/modern/{illustration,portrait,sd}.
- 선택 화면·지휘관 HUD·도감·유닛 카드·상점·벤치·정보·맵·궁극기 원화에 연결한다.
- 권총·소총·기관단총·기관총·산탄총·저격총·유탄·로켓·드론·전술 도검 연출을 대응시킨다.
- 신규 스킨을 추가하되 기존 기본·마도아카데미 스킨과 전투 규칙·세이브를 함께 지원한다.
