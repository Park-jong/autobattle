## 성격·배경

물자 회수 작전에 특화된 돌격수. 느긋한 표정 뒤로 팀원의 잔여 보급량을 빠짐없이 기억한다.

대사: “내가 맡은 구역은 끝까지 지킬게.”

## 전투·카드 연출

**전투 회수** — 짧은 중량 산탄총과 보급 회수 팩를 중심으로 기존 유닛·지휘관의 효과를 현대전 연출에 대응시킨다. 사격·피격은 동일한 전투 시간으로 재생하며 코어의 ID·수치·사거리·공격속도·효과는 그대로 연결한다. UI 무기 분류는 `shotgun`이다.

전신은 자연스러운 성인 7~8등신, 초상화는 같은 얼굴·의상의 상반신, SD는 같은 성인 캐릭터를 약 3등신으로 단순화한 전투 토큰이다. SD에서 총구는 화면 오른쪽, 몸통 높이로 향하게 해 사격 이펙트와 연결한다. 칼은 근접 베기, 드론은 어깨 오른쪽의 지원 장치가 공격 주체가 된다. 모든 이미지에서 팔과 손은 각각 두 개다.
