원래 캐릭터의 머리색·눈·체형을 계승한다. 원전의 동물 귀·꼬리·정령 신체는 통신 헤드셋·전술 장식·콜사인으로 재해석하며 실제 신체는 성인 인간 여성이다. 주요 의복은 불투명하고 가슴과 골반을 충분히 덮는다. 어깨·허리·다리의 노출과 전술 장비를 조합해 성인향 패션을 표현한다.

## 성격·배경

전장의 변화를 먼저 읽는 화력관측관. 차분한 목소리로 위험을 알리고 끝까지 통신을 유지한다.

대사: “내가 맡은 구역은 끝까지 지킬게.”

## 전투·카드 연출

**좌표 포격** — 흰색 유도탄 발사 장치와 붉은 관측 렌즈를 중심으로 기존 유닛·지휘관의 효과를 현대전 연출에 대응시킨다. 사격·피격은 동일한 전투 시간으로 재생하며 코어의 ID·수치·사거리·공격속도·효과는 그대로 연결한다. UI 무기 분류는 `rocket`이다.

전신은 자연스러운 성인 7~8등신, 초상화는 같은 얼굴·의상의 상반신, SD는 같은 성인 캐릭터를 약 3등신으로 단순화한 전투 토큰이다. SD에서 총구는 화면 오른쪽, 몸통 높이로 향하게 해 사격 이펙트와 연결한다. 칼은 근접 베기, 드론은 어깨 오른쪽의 지원 장치가 공격 주체가 된다. 모든 이미지에서 팔과 손은 각각 두 개다.
