## 설정

도시 격리 게이트의 무인 진압 병기. 변조된 피아식별 명령으로 시민과 작전부대를 차단한다.

## 외형

| 요소 | 디자인 |
|---|---|
| 큰 윤곽 | 사각 방호판으로 덮인 넓은 상체와 낮은 머리 센서, 짧고 굵은 역관절이 아닌 일반 기계 다리. 오른팔에 수직 유압 파일벙커. |
| 대표색·재질 | 차콜 #303945 · 세라믹 백색 #E5EAF0 · 경고 주황 #FF864A |
| 얼굴·센서 | 검은 센서 패널에 주황색 세로 광학 센서 하나. 얼굴·조종사는 노출하지 않는다. |
| 장비·코어 | 오른팔의 직사각 유압 파일벙커, 가슴 잠금장치형 원자로 덮개, 왼팔의 작은 방호판. |
| 전신 기본 자세 | 학원형과 같은 넓은 발 간격과 공성 추 위치. 기계 관절과 유압 실린더가 명확히 연결된다. |
| 핵심 식별 | 세로 외눈 · 사각 상체 · 오른팔 수직 파일벙커 |

## 전투 대응

**현행 규칙:** 10초마다 플레이어 유닛이 가장 많은 열에 2초 예고 후 기본 물리 피해 420. 일반 스킬 ‘균열 강타’는 현재 대상에게 ATK 250% 물리 피해.

**연출 제안:** 열 강타는 유압 압축→주황 경고등 3개 점등→파일벙커 타격으로 해석한다. 별도 광역 탄막은 추가하지 않는다.

표기한 수치는 기본 데이터 기준이다. 층·위협·전투 보정이 있으면 실제 수치는 달라질 수 있다. 스킨 표시명·연출은 기존 판정을 설명하는 제안이며 전투 데이터를 변경하지 않는다.

## SD·초상 기준

- **SD:** 세로 주황 센서·사각 상체·오른팔 파일벙커만으로 구분한다. 케이블과 경고 스티커는 생략한다.
- **초상:** 머리와 어깨, 가슴 코어 상단을 포함한다. 작은 머리만 확대하지 않고 사각 어깨가 남게 한다.
- **쌍둥이 대응:** 해당 없음
- 초상·SD는 이 폴더에서 채택한 전신만 정체성 참조로 사용한다. 기본 SD는 화면 오른쪽을 향하게 하며, 적 진영 좌우 반전은 렌더러에서 처리한다.
