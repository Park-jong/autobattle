## 설정

세르와 같은 인격 원형에서 나뉜 방호·복원 담당 안드로이드. 온화한 표정으로 적 부대를 보호하지만 몸을 감싼 구속 장비와 일정한 각도로만 움직이는 관절이 불길한 인상을 준다.

## 전투 대응

**현행 규칙:** ‘재의 장막’: 적 진영 전체(미르의 아군)에게 각자 최대 HP 8% 보호막을 6초 부여. 세르와 동일한 쌍둥이 부활 규칙(3초 / 최대 HP 50%).

**연출 제안:** 재의 장막은 늑골형 투사기가 펼치는 청록 방호 필드. 부활은 공유 인격 백업에 의한 재기동이다. 복원 장비의 설정으로 추가 치유 효과를 만들지 않는다.

표기한 수치는 기본 데이터 기준이다. 층·위협·전투 보정이 있으면 실제 수치는 달라질 수 있다. 이번 수정은 외형·설정·프롬프트 변경이며 전투 수치는 현행 데이터를 따른다.

## SD·초상 기준

- **SD:** 은회 단발·둥근 어깨·왼팔의 반원 케이지를 남긴다. 늑골형 장비는 굵은 리브 3개, 구속 링은 몸에 붙은 짧은 곡선으로 단순화한다.
- **초상:** 세르와 같은 크기의 성인 여성형 흉상. 청록 홍채·둥근 어깨와 가슴 왼쪽 반쪽 고리 코어, 장비 리브 일부가 보이게 한다.
- **쌍둥이 대응:** 세르와 동일한 성인 여성형 얼굴 골격·세라믹 재질·반쪽 고리 코어. 미르는 은회 단발·청록·곡선 장비로 구분하고 세르의 삼지 소각기를 쓰지 않는다.
- 초상·SD는 이 폴더에서 채택한 전신을 정체성 참조로 사용한다. 기본 SD는 화면 오른쪽을 향하게 하며, 적 진영 좌우 반전은 렌더러에서 처리한다.
- 기본 원화는 양발로 서 있는 안드로이드다. 장비와 몸이 연결되어 있고, 등 장치를 별도 비행 유닛으로 분리하지 않는다.
