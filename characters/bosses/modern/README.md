## 쌍둥이 안드로이드

두 개체 모두 외형 연령 25세의 성인 여성형이다. 같은 얼굴 골격·도자기 피부·금속 관절·공유 인격 코어로 쌍둥이임을 드러낸다. 양발로 걷고, 표정과 관절 동작에 미세한 부자연스러움이 남는다.

- 세르: 검은 단발·주황 센서·각진 어깨·오른팔 삼지 소각기·등 관형 반응로.
- 미르: 은회 단발·청록 센서·곡선 어깨·왼팔 늑골형 방호 투사기·등 관형 복구 장치.

장비는 신체에 연결된 프레임이며 별도 비행 유닛으로 분리하지 않는다. 초상은 얼굴과 상체가 보이는 안드로이드 흉상으로 제작한다.

## 최고통수관 바르칸

**32세, 맨발 기준 178cm, M컵의 성인 여성 절세미녀.** 도시 봉쇄망과 군수 재벌의 정점에 선 인물로, 맞춤 실크 보디스·오닉스 블랙 롱코트·샴페인 골드 장식·보라 보석을 착용한다. 허리까지 흐르는 플래티넘 장발과 열린 얼굴, 풍만한 가슴·좁은 허리·긴 다리가 핵심이다.

정밀 외골격은 어깨·손목·허리 옆·부츠에 배치한다. 얼굴과 의상 실루엣을 살리며, 메카닉의 가공 품질과 여유로운 지휘 자세로 가장 강한 적의 위상을 표현한다. 게임 수치 조정은 이번 설정 개정 범위에 포함하지 않는다.

각 폴더에서 전신을 먼저 확정하고 같은 최신 전신을 참조해 초상·SD를 만든다. **대표 이미지 12/12장 제작·채택 완료**. 전신 1024×1536, 초상·SD 1254×1254의 투명 RGBA PNG이며, 내장 image_gen으로 개별 제작했다. 개정 전 초안의 외형을 참조하지 않는다.

같은 테마의 기존 원화는 작화 참고로 사용할 수 있다. 보스의 얼굴·체형·장비는 개별 README를 따른다. 학원형 바르칸의 촉수 괴물 외형을 현대전 여성 디자인에 섞지 않는다.
