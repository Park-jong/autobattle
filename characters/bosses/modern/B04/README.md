## 설정

도시 봉쇄망과 군수 재벌을 지배하는 최고통수관. 전장의 병기까지 자신의 소유물처럼 다룬다. 군림하는 여유와 정제된 아름다움, 주문 제작한 명품 의복·보석·메카닉 장비로 다른 적보다 높은 지위를 드러낸다. 시티 오퍼레이션에서 바르칸을 성인 여성 최종 보스로 재해석한다.

M컵은 이 캐릭터의 작화용 체형 설정이다. 임의의 B/W/H 수치로 환산하지 않고 전신·초상·SD에서 같은 풍만함과 재단을 유지한다. 세부 기계 부품의 수보다 성숙한 미모·장신·풍만한 체형·명품 의상의 완성도를 우선한다.

## 전투 대응

**현행 규칙:** ‘군주의 칼날’: 현재 대상에게 ATK 300% 물리 피해, 방어력 30% 무시. HP 66%·33% 이하에서 증원 소환과 플레이어 측 보호막·카드·스킬 버프 해제. 66%: legion_crossbow 2성 ×2. 33%: abyss_devourer 2성 ×2 + war_drummer 1성 ×1.

**연출 제안:** 66%·33%에서 쇄골 브로치의 네트워크 잠금이 순차 해제되며 증원 호출·방호 해제 펄스가 발생한다. 가장 높은 지위와 강함은 정제된 명품 재단, 보석·기계 가공의 밀도, 군림하는 자세로 표현한다.

표기한 수치는 기본 데이터 기준이다. 층·위협·전투 보정이 있으면 실제 수치는 달라질 수 있다. 이번 수정은 외형·설정·프롬프트 변경이며 전투 수치는 현행 데이터를 따른다.

## SD·초상 기준

- **SD:** 성숙한 여성 얼굴·플래티넘 장발·작은 관형 보석·풍만한 상체·좁은 허리·긴 코트·도검을 남긴다. M컵의 풍만함은 의상 윤곽으로 유지하고 기계 부품은 어깨·손목의 큰 형태만 남긴다.
- **초상:** 머리부터 상흉부까지의 우아한 인물 초상. 아름다운 성인 여성 얼굴, 보라 눈, 헤어 주얼리·귀걸이·쇄골의 세 구획 브로치와 실크 보디스 상단을 포함한다. 얼굴을 헬멧·바이저로 가리지 않는다.
- 학원 테마의 촉수 괴물 설정과 분리된 현대전 여성 재해석이다. 두 테마의 체형·얼굴을 섞지 않는다.
- 초상·SD는 이 폴더에서 채택한 전신을 정체성 참조로 사용한다. 기본 SD는 화면 오른쪽을 향하게 하며, 적 진영 좌우 반전은 렌더러에서 처리한다.
- 기본 세트는 쇄골 브로치 세 구획이 모두 닫힌 1페이즈다. 후속 점등·잠금 해제는 별도 연출로 처리한다.
