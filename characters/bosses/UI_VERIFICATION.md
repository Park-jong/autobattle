# 보스 UI 연결 검증

2026-10-30 기준. 아카데미·modern 보스 원화 24장을 로컬 UI에 연결했다.

## 자동 검사

- 빌드: 타입 검사 및 Vite 빌드 통과.
- 전체 테스트: 119개 파일, 1,747개 테스트 통과.
- 보스 4종의 데이터 ID와 B01~B04 대응, 두 테마의 전신·초상·SD URL·텍스처 키·미리 읽기 목록·배포 PNG 규격 확인.
- 기본 도형 스킨과 없는 유닛의 이름·스킬·원화 없음 처리 유지.

## 브라우저 검증

분리된 브라우저 세션에서 실제 UI의 테스트 시작 기능으로 액트별 보스 직전으로 이동했다. 개발 서버에서 Chrome으로 확인했으며 기존 사용자의 런 저장과 분리했다.

| 테마 | 액트 1 골렘 | 액트 2 세르·미르 | 액트 3 바르칸 |
|---|---|---|---|
| academy | 통과 | 통과 | 촉수 괴물 통과 |
| modern | 통과 | 안드로이드 2종 통과 | 여성 최고통수관 통과 |

6개 경우 모두 보스 미리보기 전신, 전투 SD 4종 미리 읽기, 적 툴팁 초상·스킨 이름, 전투 중 클릭 정보창 전신을 확인했다. 이미지 HTTP 오류와 페이지 오류는 없었다.

추가로 390px 화면 폭에서 두 테마 쌍둥이 미리보기의 가로 넘침이 없음을 확인했다. 전투 중 academy → modern → 기본 → academy 전환에서도 정보창 원화 경로가 바뀌고, 기본 스킨에서 이미지가 제거되는 것을 확인했다.

## 적용 범위

배포 파일은 public/skins/{academy|modern}/{sd|portrait|illustration}/B01~B04.png다. 원본 이미지·전투 수치·유닛 ID·런 저장 형식을 유지하며, 웹 호스팅 배포는 수행하지 않았다.
