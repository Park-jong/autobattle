H~K컵의 매우 풍만한 가슴이다. 몸에 맞춘 불투명 안감과 흉의의 재단으로 부피를 지지하며, 컵 크기와 근육량·어깨 폭을 별개로 표현한다. 키·B/W/H와 컵 표기는 함께 따르는 작화 목표이며 B 수치 하나로 컵을 재계산하지 않는다. 주요 의복은 불투명하며, 개별 복식의 노출 위치와 직무별 장비를 유지한다.

## 성격·배경

동탁의 잔혹한 진압을 수행하는 서량 무장. 곽사와 맺은 상호 호위 계약을 빌미로 끝까지 전열을 버틴다.

대사: “불길이 먼저 닿을 거야!”

## 전투·카드 연출

**서량의 화부** — 삼지 화창이 불꽃 낙인을 남긴다. 곽사와 공유하는 군령패가 기존 쌍둥이 부활의 연결을 보여 준다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `twin_ser` |
| 내부 기원·직업 | `ember` / `mystic` |
| 기존 스킬 | 불꽃 낙인 — 대상과 인접 적에게 마법 피해 300 + 화상 3초 (초당 시전자 ATK의 100%). |

이각·곽사는 혈연 쌍둥이가 아니다. 두 군령패의 ‘서량 결의’가 기존 `twin_ser`·`twin_mir`의 연결을 대체한다. 한쪽 사망 후 3초 안에 다른 쪽도 쓰러뜨리지 않으면 사망한 쪽이 최대 HP 50%로 부활하는 현행 규칙을 따른다. 별도 계약 비용·추가 부활 조건은 없다.

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 풍만한 가슴과 각진 어깨, 상체를 앞세운 공격형. 오른손 삼지 화창과 붉은 결의패의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·H컵 폭유형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
