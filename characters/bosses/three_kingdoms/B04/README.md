H~K컵의 매우 풍만한 가슴이다. 몸에 맞춘 불투명 안감과 흉의의 재단으로 부피를 지지하며, 컵 크기와 근육량·어깨 폭을 별개로 표현한다. 키·B/W/H와 컵 표기는 함께 따르는 작화 목표이며 B 수치 하나로 컵을 재계산하지 않는다. 주요 의복은 불투명하며, 개별 복식의 노출 위치와 직무별 장비를 유지한다.

## 성격·배경

옥새와 군량을 독점해 낙양을 봉쇄한 성인 여성 폭군. 화려한 예복과 침착한 명령 속에 모든 것을 소유하려는 욕망을 숨긴다.

대사: “천하의 문도, 그 열쇠도 내 손에 있어.”

## 전투·카드 연출

**낙양을 움켜쥔 여태사** — 옥새의 세 겹 봉인이 단계적으로 풀리며 기존 증원과 버프 해제를 표현한다. 보도 한 번으로 군주의 칼날을 시각화한다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `legion_lord` |
| 내부 기원·직업 | `abyss` / `gladiator` |
| 기존 스킬 | 군주의 칼날 — 현재 대상에게 ATK 300% 물리 피해 (ARM 30% 무시). |

HP 66%·33% 이하의 기존 증원·플레이어 측 버프 해제는 옥새의 봉인 해제로 표현한다. 66% 증원 `legion_crossbow`는 관평, 33%의 `abyss_devourer`와 `war_drummer`는 허저·장비 스킨을 사용하는 강제 징발의 전장 투영으로 해석한다. 이것은 연출상 설명이며 실제 복제·배신·신규 소환 규칙은 추가하지 않는다. 기본 전신은 세 봉인이 닫힌 1페이즈다.

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 매우 풍만한 가슴과 넓은 골반, 잘록한 허리와 긴 다리의 위압적인 성숙형. 금장 보도와 세 겹 봉인이 있는 옥새, 흑자주 군령기의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·K컵 폭유형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
