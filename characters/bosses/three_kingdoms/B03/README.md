C~D컵의 자연스러운 중간 볼륨이다. 평평하게 줄이거나 H컵 이상의 풍만함으로 부풀리지 않는다. 키·B/W/H와 컵 표기는 함께 따르는 작화 목표이며 B 수치 하나로 컵을 재계산하지 않는다. 주요 의복은 불투명하며, 개별 복식의 노출 위치와 직무별 장비를 유지한다.

## 성격·배경

이각과 짝을 이뤄 수도 진입로를 봉쇄하는 성인 여성 무장. 말수가 적고 상대의 진로를 조용히 막아 세운다.

대사: “빠져나갈 틈은 남기지 않았어.”

## 전투·카드 연출

**서량의 철장막** — 철선에서 청록 장막이 펼쳐져 기존 재의 장막을 표현한다. 공유 군령패의 점등으로 부활 연결을 표시한다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `twin_mir` |
| 내부 기원·직업 | `ember` / `mystic` |
| 기존 스킬 | 재의 장막 — 아군 전체에게 최대 HP 8% 보호막 (6초). |

이각·곽사는 혈연 쌍둥이가 아니다. 두 군령패의 ‘서량 결의’가 기존 `twin_ser`·`twin_mir`의 연결을 대체한다. 한쪽 사망 후 3초 안에 다른 쪽도 쓰러뜨리지 않으면 사망한 쪽이 최대 HP 50%로 부활하는 현행 규칙을 따른다. 별도 계약 비용·추가 부활 조건은 없다.

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 중간 볼륨의 가슴과 둥근 어깨선, 무게중심을 뒤로 둔 방호형. 왼손 원형 철선과 청록 결의패의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·D컵 중간형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
