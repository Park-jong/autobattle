## 성격·배경

동탁의 관문을 지키며 통행세와 군량을 빼앗는 성인 여성 무장. 힘으로 대열을 갈라 연합군의 진입을 막는다.

대사: “관문 하나도 못 넘어서 천하를 말할 셈이야?”

## 전투·카드 연출

**사수관의 철문** — 오른손 참마도를 수직으로 들어 기존 열 강타의 한 열을 예고한다. 방패를 디딘 뒤 예고 열로 칼을 내리친다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `gate_breaker` |
| 내부 기원·직업 | `abyss` / `guardian` |
| 기존 스킬 | 균열 강타 — 현재 대상에게 ATK 250% 물리 피해. |

원래 `gate_breaker`의 열 강타 예고·판정·시점을 그대로 따른다. 예고 문양은 화면 한 열에 표시하며 별도 관문 오브젝트나 파괴 규칙은 추가하지 않는다.

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 풍만한 상체와 두꺼운 팔, 문처럼 넓게 선 중장 무장형. 긴 참마도와 사수관 문양 대방패의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·I컵 폭유형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
