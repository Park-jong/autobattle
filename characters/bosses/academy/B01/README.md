## 설정

학원 정문을 지키던 거대 결계 골렘. 봉쇄 의식이 수호 명령을 뒤집어, 탈출하려는 이들을 침입자로 판단한다.

## 외형

| 요소 | 디자인 |
|---|---|
| 큰 윤곽 | 머리가 작은 문루형 상체, 사각 성문을 닮은 넓은 어깨, 짧고 굵은 두 다리. 한쪽 팔 전체가 세로로 긴 공성 추다. |
| 대표색·재질 | 현무암 #343A46 · 낡은 아이보리 #D8D0BC · 봉인 청록 #59D3C2 |
| 얼굴·센서 | 석재 가면 중앙에 청록색 세로 눈 하나. 입과 인간 피부는 없다. |
| 장비·코어 | 오른팔의 직사각 봉인문 공성 추, 가슴의 잠긴 열쇠구멍 코어, 어깨의 부서진 교표 조각. |
| 전신 기본 자세 | 발을 넓게 벌린 낮은 중심, 공성 추는 바닥에 대지 않고 몸 옆에 세운다. 머리와 가슴 코어를 가리지 않는다. |
| 핵심 식별 | 세로 외눈 · 문루형 어깨 · 오른팔 공성 추 |

## 전투 대응

**현행 규칙:** 10초마다 플레이어 유닛이 가장 많은 열에 2초 예고 후 기본 물리 피해 420. 일반 스킬 ‘균열 강타’는 현재 대상에게 ATK 250% 물리 피해.

**연출 제안:** 열 강타 직전 공성 추의 세로 홈 3개가 점등하고 흉부 봉인이 열린다. 열 범위와 카운트다운은 게임에서 그린다.

표기한 수치는 기본 데이터 기준이다. 층·위협·전투 보정이 있으면 실제 수치는 달라질 수 있다. 스킨 표시명·연출은 기존 판정을 설명하는 제안이며 전투 데이터를 변경하지 않는다.

## SD·초상 기준

- **SD:** 머리·상체 덩어리와 세로 공성 추로 읽힌다. 돌 균열은 큰 2~3개만 남기고 교표는 추상 문양으로 단순화한다.
- **초상:** 머리와 어깨, 가슴 코어 상단을 포함한다. 작은 머리만 확대하지 않고 사각 어깨가 남게 한다.
- **쌍둥이 대응:** 해당 없음
- 초상·SD는 이 폴더에서 채택한 전신만 정체성 참조로 사용한다. 기본 SD는 화면 오른쪽을 향하게 하며, 적 진영 좌우 반전은 렌더러에서 처리한다.
