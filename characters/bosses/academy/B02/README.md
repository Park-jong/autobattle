## 설정

학원 연금 대화로에서 분리된 두 화로령 중 점화의 반쪽. 미르와 하나의 혼불을 나눠 가져 재가 되어도 서로를 다시 불러낸다.

## 전투 대응

**현행 규칙:** ‘불꽃 낙인’: 현재 대상과 인접 적에게 마법 피해 300 + 3초 화상(초당 시전자 ATK 100%). 한쪽 사망 뒤 3초 안에 다른 쪽도 사망하지 않으면 쓰러진 쪽이 최대 HP 50%로 부활.

**연출 제안:** 불꽃 낙인은 삼지 화로의 좁은 화염으로 표시. 쌍둥이 연결·부활 카운트다운은 별도 전투 연출로 둔다.

표기한 수치는 기본 데이터 기준이다. 층·위협·전투 보정이 있으면 실제 수치는 달라질 수 있다. 스킨 표시명·연출은 기존 판정을 설명하는 제안이며 전투 데이터를 변경하지 않는다.

## SD·초상 기준

- **SD:** 삼각형 실루엣·솟은 왕관·삼지 지팡이를 크게 남긴다. 불꽃은 주홍 덩어리 1개, 작은 불씨는 생략한다.
- **초상:** 가면·두건 또는 왕관·가슴 반쪽 고리 코어를 포함한다. 지팡이/화로륜은 얼굴을 가리지 않는 일부만 남긴다.
- **쌍둥이 대응:** B03 미르와 같은 도자기·구리 재질과 반쪽 고리 코어. 세르는 각지고 상승하는 형태, 미르는 둥글고 감싸는 형태.
- 초상·SD는 이 폴더에서 채택한 전신만 정체성 참조로 사용한다. 기본 SD는 화면 오른쪽을 향하게 하며, 적 진영 좌우 반전은 렌더러에서 처리한다.
