## 전투 대응

**현행 규칙:** ‘재의 장막’: 적 진영 전체(미르의 아군)에게 각자 최대 HP 8% 보호막을 6초 부여. 세르와 동일한 쌍둥이 부활 규칙(3초 / 최대 HP 50%).

**연출 제안:** 재의 장막은 화로륜의 동심원과 반구형 보호막으로 해석. 전체 보호막은 게임 연출로 분리한다.

표기한 수치는 기본 데이터 기준이다. 층·위협·전투 보정이 있으면 실제 수치는 달라질 수 있다. 스킨 표시명·연출은 기존 판정을 설명하는 제안이며 전투 데이터를 변경하지 않는다.

## SD·초상 기준

- **SD:** 둥근 두건·종 망토·작은 구리 고리의 세 형태를 유지. 반투명 보호막은 기본 SD에 굽지 않는다.
- **초상:** 가면·두건 또는 왕관·가슴 반쪽 고리 코어를 포함한다. 지팡이/화로륜은 얼굴을 가리지 않는 일부만 남긴다.
- **쌍둥이 대응:** B02 세르와 같은 도자기·구리 재질과 반쪽 고리 코어. 미르는 둥근 방어형이며 세르의 삼각 왕관·삼지 지팡이를 쓰지 않는다.
- 초상·SD는 이 폴더에서 채택한 전신만 정체성 참조로 사용한다. 기본 SD는 화면 오른쪽을 향하게 하며, 적 진영 좌우 반전은 렌더러에서 처리한다.
