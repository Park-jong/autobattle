## 설정

학원의 방위 의식을 삼켜 봉쇄망 그 자체의 주인이 된 심연의 군주. 학내 봉인 장치와 고대 금속이 살에 융합되어 왕관과 의식 장갑처럼 남았다. 하나의 거대한 몸에서 뻗은 촉수로 전장을 통제하고 봉인이 풀릴 때마다 금서 군단을 부른다.

modern 바르칸은 178cm·M컵의 성인 여성 최고통수관이며, 이 아카데미 디자인은 독립된 비인간 촉수 괴물이다.

## 전투 대응

**현행 규칙:** ‘군주의 칼날’은 현재 대상에게 ATK 300% 물리 피해, 방어력 30% 무시. HP 66%·33% 이하에서 증원을 소환하고 플레이어 측 보호막·카드·스킬 버프를 해제한다. 66%: `legion_crossbow` 2성 ×2. 33%: `abyss_devourer` 2성 ×2 + `war_drummer` 1성 ×1.

**연출 제안:** 군주의 칼날은 판각 촉수의 내려치기로 표현한다. 페이즈 전환은 코어 봉인 순차 개방과 촉수의 맥동, 증원과 해제 파동으로 표현한다. 촉수 잡기·이동·추가 상태 이상은 새로 만들지 않는다. 전투 수치는 현행 데이터를 유지한다.

## 초상·SD

- 초상: 왕관형 갑각·외눈·세 구획 코어와 위쪽 촉수 뿌리를 포함한 괴물 흉상. 여섯 촉수 전체를 좁은 초상 안에 억지로 넣지 않는다.
- SD: 인간형 등신을 적용하지 않는다. 큰 중앙 덩어리 하나와 굵고 짧은 촉수 여섯으로 압축하고, 흡반·금속 판각은 큰 형태만 남긴다.
- SD 원본은 화면 오른쪽을 향하는 전투 자세. 접지 기준은 아래 촉수 끝이며, 사람의 발·손을 추가하지 않는다.
- 기본 이미지는 닫힌 봉인 3개를 가진 1페이즈다. 소환수·바닥 마법진·파동은 별도 전투 효과로 둔다.
