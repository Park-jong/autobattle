# 마도아카데미 — 봉쇄 의식의 수호자들

[보스 전체 목록](../README.md) · [공통 제작 기준](../ART_DIRECTION.md) · [제작 진행](../PROGRESS.md)

학원에 설치된 골렘과 화로령, 방위 의식을 삼킨 심연의 촉수 군주를 적으로 재해석한다. 일반 여성 유닛의 제복 변주와 달리 돌·도자기·중장 갑옷으로 보스 정체성을 구분한다. 기존 학원 유닛의 애니메이션 선화·셀 명암은 유지한다.

| 번호 | 설정 | 핵심 식별 |
|---|---|---|
| B01 | [봉인문 파괴 골렘](B01/README.md) | 세로 외눈 · 문루형 어깨 · 오른팔 공성 추 |
| B02 | [쌍둥이 화로령 세르](B02/README.md) | 주홍 · 삼각 망토 · 위로 솟은 왕관 · 삼지 화로 |
| B03 | [쌍둥이 재의령 미르](B03/README.md) | 회보라·청록 · 둥근 두건 · 종 망토 · 구리 화로륜 |
| B04 | [봉쇄 의식의 군주 바르칸](B04/README.md) | 왕관형 갑각 · 세로 외눈 · 세 구획 봉인 · 촉수 6개 |

각 폴더에서 전신을 먼저 확정하고 동일 원화를 참조해 초상·SD를 만든다. **대표 이미지 12/12장 제작·채택 완료**. 전신 1024×1536, 초상·SD 1254×1254의 투명 RGBA PNG다. 바르칸은 사용자 지정 촉수 괴물 설정을 적용했다.

학원 원화는 characters/U01/illustration.png 등을 작화 참고로 사용할 수 있지만, 인간 얼굴·제복·체형을 보스에 복사하지 않는다.
