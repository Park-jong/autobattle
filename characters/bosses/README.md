# 보스 스킨 설계

상태: **academy 12/12 · modern 12/12, 대표 이미지 총 24/24 제작·채택 및 게임 UI 연결 완료**.

기존 두 원화 테마인 **마도아카데미(`academy`) / 시티 오퍼레이션(`modern`)**에 보스 아트를 확장한다. 두 가지 스킨의 의미는 이 두 테마로 정했다. 기본 도형 스킨은 별도 테마로 세지 않는다.

3개 보스전의 실제 유닛 4종을 각각 관리한다. 세르와 미르는 개별 유닛이므로 각자 전신·초상화·SD가 필요하다. 목표는 **4종 × 2테마 × 3종 = 대표 PNG 24장**이다. 아카데미와 현대전 각 12장이 완성되어 전체 **24/24장**을 제작·채택했다.

각 B 폴더에는 `README.md`, `illustration.prompt.md`, `portrait.prompt.md`, `sd.prompt.md`를 둔다. 채택 이미지는 동일 폴더의 `illustration.png`, `portrait.png`, `sd.png`로 저장한다. academy·modern 각 4종의 대표 PNG 24장과 modern 최초 전신 후보 4장을 보관했다. [academy 이미지 목록](academy/README.md) · [modern 이미지 목록](modern/README.md). 각 테마 폴더에 별도 검증 기록과 실제 생성 이력을 보관한다.

## 디자인 방향

- 보스는 일반 여성 유닛 로스터와 별도 아트 분류다. 성문 파괴자는 골렘/무인 병기, 쌍둥이는 학원의 비인간 주술체와 현대전의 성인 여성형 이족 안드로이드로 구분한다. 현대전 쌍둥이는 몸에 부착한 괴이한 산업 장비를 사용한다.
- 바르칸은 학원 테마의 비인간 촉수 괴물과 현대전의 여성 최고통수관을 각각 독립 디자인으로 관리한다. 현대전은 **32세 성인 여성·맨발 178cm·M컵의 절세미녀**, 맞춤 명품 의복·보석·정밀 외골격을 결합한 최종 보스다.
- 학원 테마는 금지된 의식으로 뒤틀린 수호 존재, 현대전 테마는 봉쇄망에 장악된 병기·지휘관으로 해석한다.
- 두 테마의 보스 대응은 역할·상징·주장비 위치로 이어간다. 세르의 삼각/삼지와 미르의 곡선/고리, 바르칸의 지위 상징과 세 구획 봉인은 유지하되 테마별 성별·얼굴·체형은 각 설정을 따른다. 보스 간 구분은 색뿐 아니라 몸의 형태·장비로 확보한다.
- 별도 페이즈 이미지, 쌍둥이 합동 이미지, 배경 포함 키아트, 애니메이션은 초기 24장에 포함하지 않는다. 바르칸은 1페이즈 기준 원화 한 세트이며 전환은 별도 효과로 설계한다.

## 프롬프트 사용

1. 보스 README에서 설정을 확인하고 `illustration.prompt.md`로 전신을 먼저 만든다.
2. 전신을 검수한 뒤 대표 `illustration.png`로 채택한다.
3. 같은 폴더 전신을 실제 참조 이미지로 첨부하고 초상화와 SD 프롬프트를 실행한다. 파일명만 프롬프트에 쓰는 것으로 참조가 전달되지는 않는다.
4. 투명도·형태·일관성·게임 축소 가독성을 확인하고 진행표를 갱신한다.

프롬프트는 각각 독립 실행 가능한 영문 본문과 한국어 제작 메모를 포함한다. 참조 전신이 아직 없으면 파생 이미지는 제작 대기한다. 이미지 생성 도구를 사용할 때는 `transparent_background: true`를 지정한다. 제작 이력은 이미지 생성 후에만 기록하며 미생성 이미지를 검증 완료로 표시하지 않는다.


## 게임 적용

src/ui/skin/bossRoster.ts의 보스 매핑과 테마별 표시 설정을 통해 전투 SD·툴팁 초상·정보창 전신을 연결했다. 보스 노드와 액트 소개의 미리보기에도 전신을 표시한다. 기본 도형 스킨은 기존 도형을 사용한다.
