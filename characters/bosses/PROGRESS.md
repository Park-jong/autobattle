## 권장 제작 순서

1. academy/B01 전신 → 초상 → SD: 기존 학원 유닛과 재질·선화·SD 밀도를 맞춘다.
2. academy/B02·B03 전신: 쌍둥이의 공통 재질과 다른 윤곽을 함께 검수한 뒤 각각 초상·SD를 만든다.
3. academy/B04: 왕관형 갑각·세로 외눈·세 구획 봉인·촉수 6개를 가진 비인간 최종 보스 실루엣을 검수한다.
4. modern/B01 → B02·B03 → B04: 쌍둥이는 괴이한 장비를 붙인 성인 여성형 이족 안드로이드로, 바르칸은 32세·178cm·M컵의 명품/메카닉 여성 최고통수관으로 제작한다. 학원형과 역할·상징·장비 위치를 대응시키고, 얼굴·성별·체형은 각 테마 설정을 따른다.
5. 24장 채택 후 배포 축소·게임 연결. 테마 하나를 먼저 완성하면 해당 12장 단위로 연결할 수 있다.

전신은 신규 디자인 생성, 초상·SD는 같은 테마 같은 보스 전신을 참조한 편집/파생 생성으로 진행한다. 쌍둥이를 한 캔버스에 동시에 만들지 않는다.

## 상태 갱신 규칙

- PNG 상태: 미제작 → 후보 생성 → 시각 검수 → 채택.
- 게임 연결: 대기 → 매핑·내보내기 → 화면 검증 완료.
- 후보는 `illustration_v01.png`, `portrait_v01.png`, `sd_v01.png`처럼 보존하고 채택본만 대표 파일명으로 둔다.
- 수정 프롬프트는 `illustration.refinement.prompt.md`처럼 별도로 남기며 최초 프롬프트를 덮어쓰지 않는다.
- 이미지 생성 도구의 실제 결과 경로·사용한 참조·검수 의견을 아래 이력에 기록한다.
