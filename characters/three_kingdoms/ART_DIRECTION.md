# 연화삼국 — 공통 작화·체형 기준

[스킨 목록](README.md) · [modern 참고](../modern/README.md) · [적 보스 목록](../bosses/three_kingdoms/README.md)

상태: **콘셉트·이미지 프롬프트 111개 작성. 이미지 미생성.** 이 문서는 향후 원화 제작의 기준이며 지금 이미지 생성을 실행하는 지시가 아니다.

## 공통 인물·화풍

- 지휘관·유닛·보스 37명 모두 22세 이상 성인 인간 여성. 남성 얼굴·수염 대신 이름·무기·상징·성격으로 원형을 알아보게 한다.
- modern 문서의 기본 설정 → 외형·복식 → 성격·배경 → 전투·카드 연출 → 이미지 저장 구성을 계승한다. 삼국지 인물은 독립 디자인이므로 원래 아카데미/modern 얼굴·머리색·체형을 강제로 계승하지 않는다.
- 선명한 2D 애니메이션 선화와 정돈된 셀 명암. 금속 갑주·옥·비단·천의 재질을 나누고 얼굴·주장비·세력색을 먼저 읽히게 한다.
- 역사 복식의 엄밀한 복원보다 교차깃·전포·견갑·군기·관·비녀를 조합한 판타지 모에화를 따른다. 실존 작품의 특정 캐릭터 디자인은 차용하지 않는다.
- 팔·손은 각각 두 개, 눈은 두 개. 하후돈의 한쪽 눈은 안대로 가리고 상처나 고어는 묘사하지 않는다. 꿩깃·뿔 모양 장식은 장비이며 신체기관이 아니다.

## 체형 기준

| 구분 | 컵 | 작화 기준 |
|---|---|---|
| 빈유형 `small` | A | 작고 평평한 상체. 패딩·갑주로 가슴을 크게 보이게 만들지 않는다. |
| 중간형 `medium` | C~D | 자연스러운 중간 볼륨. 같은 유형 안에서도 체격과 근육은 다를 수 있다. |
| 폭유형 `large` | H~K | 큰 가슴과 이를 지지하는 의상 재단. K컵 초과·다른 유형으로의 임의 변경은 없다. |

키는 맨발·장식 제외, B/W/H는 cm 단위의 디자인 참고 수치다. 개별 문서의 컵 크기를 직접 따른다. B 수치 하나를 컵으로 환산하지 않는다. 가슴 유형과 성인 외형, 어깨·등·허리·골반·근육을 함께 읽히게 한다.

## 복식

교차깃 탑·어깨 트임·짧은 전포·분할 갑편·덧치마와 반바지·높은 장화를 개인별로 조합한다. 피부 노출은 어깨·쇄골·좁은 허리·허벅지 중심이며, 개별 의상에 적은 경우 윗가슴 선을 일부 드러낸다. 주요 부위는 불투명 의복으로 가리고 노출 강도보다 무장·책사·군주의 직무와 실루엣을 우선한다.

## 세력 식별

| 세력 | 색·상징 | 복식·장비 방향 |
|---|---|---|
| 위 | 먹색·코발트·은색 / 흑봉·현무 | 절제된 전포, 직선형 갑주, 군령패·철선·정교한 검 |
| 촉 | 백색·비취·금색 / 복숭아꽃·청룡 | 매듭과 맹약 문양, 방패·청룡 무기, 따뜻한 인상 |
| 오 | 아이보리·주홍·금색 / 호랑이·물결 | 가벼운 수군복, 파도 문양, 화계 등롱·부채·수극 |
| 동탁 | 철회색·흑자주·적동 / 관문·옥새 | 서량 갑편, 자주 군끈, 철제 장비와 권력의 금장 |

군주 세 명은 관·지휘선·군령패로 유닛보다 높은 지위를 보인다. 여포의 꿩깃·화극과 동탁의 세 갈래 금관·옥새는 구분한다. 이각은 오른손 삼지 화창·각진 견갑·주황, 곽사는 왼손 원형 철선·둥근 견갑·청록으로 구별한다.

## 향후 이미지 규격

| 종류 | 구도·목표 |
|---|---|
| 전신 | 세로 2:3, 약 7~8등신, 눈높이의 3/4 시점. 장식·발끝·주무기를 프레임 안에 배치. |
| 초상화 | 정사각형, 성인 얼굴과 어깨·상반신. 얼굴·헤어·장식·체형·복식을 전신과 통일. |
| 전투 SD | 정사각형, 약 3등신. 성인 캐릭터의 머리·주장비·세력색·체형 차이를 단순화해 보존. |
| 배경·파일 | 향후 투명 PNG. 전신 `illustration.png`, 초상 `portrait.png`, SD `sd.png`. 현재 파일 없음. |

SD의 기본 전투 방향은 화면 오른쪽, 적 방향 반전은 기존 렌더링 방식을 따른다. 장창·대도·활은 얼굴을 가리지 않는 각도로 배치하고, 군기·맹수·용의 문양은 별도 전투 유닛처럼 보이지 않게 한다. 초상·SD는 향후 채택된 같은 인물의 전신을 참조한다.

## 준비된 프롬프트 사용

각 인물 폴더의 `illustration.prompt.md` → `portrait.prompt.md` / `sd.prompt.md` 순서로 사용한다. 전신을 먼저 생성·검수·채택한 후 같은 전신 파일을 초상화·SD 생성의 실제 이미지 입력으로 첨부한다. 현재 전신은 없으므로 파생 이미지용 프롬프트는 전신 참조 대기다. 단순한 파일명 기입만으로 이미지가 전달되지는 않는다.

각 프롬프트는 독립 실행 가능한 공통 화풍·개별 한국어 설정·체형 수치·구도·장비 자세·출력 조건을 포함한다. 생성 시 `transparent_background: true`를 사용하고 전신·초상화·SD에 공격 이펙트를 넣지 않는다. 사용한 실제 참조·생성 이력·검수 결과는 이미지 제작 이후에만 기록한다.

## 전투 표현의 경계

이름·장비·이펙트는 콘셉트이며 실제 구현은 후속 작업이다. 내부 ID·기원·직업·사거리·공격속도·피해·회복·이동·부활·소환·페이즈 조건은 기존 데이터 그대로 대응한다. 창이 길거나 활을 들었다는 이유로 사거리를 바꾸지 않고, 화선·청룡·적토 문양을 실제 소환수로 추가하지 않는다. 보스 부활의 군령패도 자동 추가 규칙이 아니라 기존 기믹의 시각적 해석이다.
