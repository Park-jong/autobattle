# 연화삼국 — 삼국지 모에화 스킨

위·촉·오의 지휘관 3명, 유닛 30명, 별도 적 보스 4명으로 구성한 삼국지 스킨 콘셉트. **전원 22세 이상 성인 인간 여성**이며, 기존 인물의 이름·상징·일화를 애니메이션풍 여성 캐릭터로 재해석한다. 현재 **디렉토리·콘셉트·이미지 생성 프롬프트 MD**를 준비했다.

[modern 형식 참고](../modern/README.md) · [공통 작화 기준](ART_DIRECTION.md) · [제작 진행](PROGRESS.md) · [적 보스 목록](../bosses/three_kingdoms/README.md)

예정 스킨 ID는 `three_kingdoms`다. 현재 게임의 선택 가능한 스킨으로 등록하지 않았으며 JSON·UI·게임 규칙은 변경하지 않았다. **37명 × 전신·초상화·SD = 프롬프트 111개 작성 완료**. 원화·배포용 이미지·에셋 매니페스트는 아직 없다.

## 세계관·적대 관계

**“낙양의 옥새와 군량을 독점한 여태사 동탁에 맞서, 위·촉·오의 세 군주가 한시적인 연합을 맺는다.”**

세력은 **위·촉·오·동탁의 네 개**로 고정한다. 표에서 ‘동탁군’은 동탁 세력의 군대를 뜻하며 다섯 번째 세력이 아니다. 다른 군웅의 별도 세력은 만들지 않는다.

- 위·촉·오는 천하의 미래를 두고 경쟁하지만, 이번 여정에서는 동탁의 수도 봉쇄를 푸는 데 협력한다.
- 동탁과 관문 수비대·직속 진압군이 주 적대 세력이다. 동탁군의 영입 유닛은 고순·장제·서영·이유·초선·동백·여포로, 출신별 카드 분류는 동탁을 유지하되 현재는 이탈자·잠입자·임시 공투자다.
- 같은 인물의 적·아군 중복 배치는 기존 게임의 편성 표현을 따른다. 영입 유닛과 별도 보스는 서로 다른 인물이며, 동탁은 네 번째 선택 지휘관으로 추가하지 않는다.
- 역사적 시점·실제 친족관계·진영 이동을 그대로 재현하는 연표가 아닌 독립적인 삼국지 판타지다. 관평·황충의 장비, 조운·하후돈의 직업, 이유의 이탈 등은 이 스킨 전용 설정이다.

## 체형·가슴크기 기준

37명 전체는 **빈유형 8명·중간형 12명·폭유형 17명**이다. 지휘관·일반 유닛 33명은 빈유형 8명·중간형 11명·폭유형 14명, 적 보스 4명은 중간형 1명·폭유형 3명이다.

| 구분 | 작화용 키 | 컵 범위 | 필수 실루엣 |
|---|---|---|---|
| 빈유형 | `small` | **A컵** | 실제로 작고 평평한 가슴. 중간형 볼륨으로 그리지 않는다. |
| 중간형 | `medium` | **C~D컵** | 자연스러운 중간 볼륨. 빈유나 폭유와 구분한다. |
| 폭유형 | `large` | **H~K컵** | 매우 풍만한 가슴과 이를 받치는 의복 재단. K컵을 넘기지 않는다. |

- 모든 개인 문서에 키(cm), 쓰리사이즈 B/W/H(cm), 체형 구분, **개별 컵 크기**를 명시한다. 컵 글자만 범위 없이 추정하도록 두지 않는다.
- B/W/H는 가슴둘레·허리둘레·엉덩이둘레의 작화 참고치다. 가슴둘레만으로 컵 크기를 환산하지 않으며, 개별 컵 표기를 함께 따른다.
- 작은 키나 A컵을 미성년 체형으로 표현하지 않는다. 전원 성인 얼굴·골격·직무와 명시된 나이를 유지한다.
- 어깨 폭·근육·골반·키는 가슴 유형과 독립적으로 설계한다. 전신·초상화·SD에서 같은 캐릭터의 유형과 복식을 유지한다.

## 디렉토리 구조·문서 범위

modern의 `characters/modern/{C01~C03,U01~U30}/README.md`와 `characters/bosses/modern/{B01~B04}/README.md` 구조를 따른다.

```text
characters/
  three_kingdoms/
    README.md                 # 세계관·세력·전체 로스터
    ART_DIRECTION.md          # 전원 공통 작화·체형 기준
    PROGRESS.md               # 콘셉트와 이미지 상태
    C01/README.md             # 유비
    C01/illustration.prompt.md
    C01/portrait.prompt.md
    C01/sd.prompt.md
    C02/README.md             # 손권
    C03/README.md             # 조조
    U01/README.md
    ...                       # U02~U29도 각각 개인 문서
    U30/README.md
  bosses/
    three_kingdoms/
      README.md               # 적대 세력·보스 순서
      B01/README.md           # 화웅
      B02/README.md           # 이각
      B03/README.md           # 곽사
      B04/README.md           # 동탁
```

모든 C01~C03·U01~U30·B01~B04 폴더에 `illustration.prompt.md`, `portrait.prompt.md`, `sd.prompt.md`가 있다. [제작 진행](PROGRESS.md)에서 111개 프롬프트를 종류별로 열 수 있다.

전신 프롬프트는 신규 디자인용이다. 초상화·SD는 채택한 같은 캐릭터의 전신 파일을 실제 참조 이미지로 첨부해야 하므로 현재 전신 참조 대기 상태다. 각 프롬프트는 영문 실행 본문과 한국어 개별 설정, 체형·컵 크기, 장비별 자세와 검수 항목을 포함한다.

이미지는 생성하지 않았다. 향후 제작 시 각 인물 폴더에 `illustration.png`, `portrait.png`, `sd.png`를 저장하고, 실제 생성 때만 생성 이력과 이미지 검수 상태를 기록한다.
