C~D컵의 자연스러운 중간 볼륨이다. 평평하게 줄이거나 H컵 이상의 풍만함으로 부풀리지 않는다. 키·B/W/H와 컵 표기는 함께 따르는 작화 목표이며 B 수치 하나로 컵을 재계산하지 않는다. 주요 의복은 불투명하며, 개별 복식의 노출 위치와 직무별 장비를 유지한다.

## 성격·배경

위의 신속한 원거리 지원을 맡는 궁수. 목표를 정하면 빠르지만 동료가 따라올 시간을 세심하게 계산한다.

대사: “먼저 가 있을게. 화살로 길을 표시하지.”

## 전투·카드 연출

**천리의 청궁** — 짙은 청색 응축 화살로 기존 공허탄의 타격 범위를 표현한다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `void_sniper` |
| 내부 기원·직업 | `abyss` / `marksman` |
| 기존 스킬 | 공허탄 — HP가 가장 많은 적에게 ARM 무시 ATK 350 / 400 / 500% 물리 피해. |

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 중간 볼륨의 가슴과 긴 팔, 곧은 등선의 사수형. 긴 청색 각궁과 세 갈래 깃 화살의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·C컵 중간형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
