## 성격·배경

조조 곁을 지키는 위의 호위무장. 잘 먹고 잘 자는 것을 임무의 일부로 여기며 간식 주머니를 따로 챙긴다.

대사: “든든하게 먹었으니, 든든하게 막아야지.”

## 전투·카드 연출

**호치의 철권** — 철퇴 타격 뒤 푸른 호랑이 기운이 몸으로 돌아와 기존 회복 효과를 표현한다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `abyss_devourer` |
| 내부 기원·직업 | `abyss` / `gladiator` |
| 기존 스킬 | 포식 — ATK 200/240/320% 물리 피해. 이 스킬로 처치하면 이번 전투 최대 HP +60/90/150. |

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 큰 가슴과 넓은 골반, 두꺼운 팔·허벅지의 중량 근력형. 호랑이 머리 철퇴와 두꺼운 완갑의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·J컵 폭유형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
