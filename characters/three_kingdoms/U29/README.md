A컵 수준의 작고 평평한 가슴으로 그린다. 의상의 주름이나 갑옷으로 C컵 이상의 둥근 돌출을 만들지 않는다. 작은 가슴과 성인 얼굴·골격을 함께 유지한다. 키·B/W/H와 컵 표기는 함께 따르는 작화 목표이며 B 수치 하나로 컵을 재계산하지 않는다. 주요 의복은 불투명하며, 개별 복식의 노출 위치와 직무별 장비를 유지한다.

## 성격·배경

위의 오래된 신뢰를 짊어진 무장. 한쪽 안대는 상처를 드러내지 않는 외형 표식이며 거친 태도 뒤에 세심한 행정 감각이 있다.

대사: “망설이지 마. 내가 먼저 베어 열겠다.”

## 전투·카드 연출

**독안의 결의검** — 한 번의 묵직한 검선과 청색 잔상으로 기존 무명의 일섬을 표현한다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `muhon` |
| 내부 기원·직업 | `abyss` / `assassin` |
| 기존 스킬 | 무명의 일섬 — 직선상의 적을 모두 관통하며 질주, ATK 300 / 350 / 600% 물리 피해. 처치 1명당 마나 30 회복. |

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 평평한 가슴과 넓은 등, 길고 단련된 팔다리의 장신 검사형. 넓은 직도와 흰색 칼집의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·A컵 빈유형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
