## 외형·복식

| 항목 | 설정 |
|---|---|
| 키 | 174 cm · 맨발·머리 장식 제외 |
| 쓰리사이즈 B/W/H | 91/66/94 cm |
| 체형 구분 | 중간형 (`medium`) |
| 가슴크기 | **D컵** · 중간형 |
| 체형 | 중간 볼륨의 가슴과 발달한 등, 넓게 선 방호형 |
| 머리색·헤어스타일 | 흑색 #282D32 머리를 높은 매듭으로 묶고 흰 두건 |
| 눈색·눈매 | 갈청색 #6C8489, 단단하고 신중한 눈매 |
| 얼굴·표정 | 단단한 턱선과 낮게 정돈한 눈썹. 입을 다문 신중한 표정에 병서를 읽을 때 집중한 눈빛이 더해진다. |
| 피부 | 옅게 그을린 베이지색의 자연스러운 성인 인간 피부. |
| 복식 | 백색 어깨 덧옷과 주홍 불투명 전투 상의, 작은 흉갑, 기마 반바지와 긴 갑편 |
| 대표 장비 | 닻 문양 방패와 군도, 접힌 병서 |
| 세력색·상징 | 아이보리·주홍·금색 / 호랑이·물결 |

C~D컵의 자연스러운 중간 볼륨이다. 평평하게 줄이거나 H컵 이상의 풍만함으로 부풀리지 않는다. 키·B/W/H와 컵 표기는 함께 따르는 작화 목표이며 B 수치 하나로 컵을 재계산하지 않는다. 주요 의복은 불투명하며, 개별 복식의 노출 위치와 직무별 장비를 유지한다.

## 성격·배경

공부를 통해 전술의 폭을 넓힌 오의 무장. 작전 틈마다 읽는 병서에는 실전 경험을 빼곡하게 적어 둔다.

대사: “한 번 더 읽고, 한 번 덜 다치자.”

## 전투·카드 연출

**백의의 수군방패** — 방패 위에 담금질한 금속 무늬가 점등해 기존 방어 강화 효과를 표시한다.

|---|---|

| 내부 기원·직업 | `ember` / `guardian` |

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 중간 볼륨의 가슴과 발달한 등, 넓게 선 방호형. 닻 문양 방패와 군도, 접힌 병서의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·D컵 중간형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
