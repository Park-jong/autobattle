## 성격·배경

음률처럼 전열과 화공의 타이밍을 맞추는 오의 군사. 연주 도중 틀린 음을 들으면 무심코 고개를 돌리는 버릇이 있다.

대사: “바람이 맞았어. 이제, 불을 올려.”

## 전투·카드 연출

**적벽의 홍련군사** — 부채가 붉은 예고 문양을 남긴 뒤 화전이 낙하해 기존 대분화의 예언의 지연 타격을 표현한다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `volcano_oracle` |
| 내부 기원·직업 | `ember` / `mystic` |
| 기존 스킬 | 대분화의 예언 — 4초 예고 후 적 전체에 마법 피해 300 / 450 / 1200 + 화상 3초 (초당 시전자 ATK의 100%). |

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 풍만한 가슴과 곧은 어깨, 긴 손가락의 우아한 지휘형. 홍련 깃털 부채와 작은 현악기 장식의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·H컵 폭유형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
