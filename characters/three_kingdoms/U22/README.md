## 성격·배경

동탁의 가문에서 자랐으나 폭정과 선을 긋고 나온 22세 성인 여성. 가문의 이름보다 자신의 선택으로 인정받으려 한다.

대사: “내가 설 곳은 내가 정해.”

## 전투·카드 연출

**자전의 서량궁** — 화살 주변 자주색 바람 고리가 기존 폭풍 화살을 표현한다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `wind_hunter` |
| 내부 기원·직업 | `forest_pact` / `marksman` |
| 기존 스킬 | 폭풍 화살 — 부채꼴로 화살 5발, 각 ATK 70 / 90 / 120% 물리 피해. 맞은 적은 3초간 AS -20%. |

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 작고 평평한 가슴, 가벼운 체격과 곧은 자세의 성인 궁수. 자수정 장식 각궁과 흑옥 화살집의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·A컵 빈유형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
