C~D컵의 자연스러운 중간 볼륨이다. 평평하게 줄이거나 H컵 이상의 풍만함으로 부풀리지 않는다. 키·B/W/H와 컵 표기는 함께 따르는 작화 목표이며 B 수치 하나로 컵을 재계산하지 않는다. 주요 의복은 불투명하며, 개별 복식의 노출 위치와 직무별 장비를 유지한다.

## 성격·배경

누구의 혼인 상대보다 자신의 무예로 기억되길 원하는 오의 무장. 궁술 이미지와 근접 쌍도 역할을 함께 재해석한다.

대사: “내가 겨눈 길은 내가 열어!”

## 전투·카드 연출

**궁요희의 쌍인** — 쌍도가 주홍 원호를 그리며 기존 불꽃 칼춤을 표현한다. 활은 보조 상징이며 추가 사격을 만들지 않는다.

| 대응 항목 | 현행 데이터 기준 |
|---|---|
| 기존 유닛 ID | `ember_bladedancer` |
| 내부 기원·직업 | `ember` / `assassin` |
| 기존 스킬 | 불꽃 칼춤 — 2초간 0.4초마다 주변 1칸 적에게 마법 피해 50 / 75 / 120 (총 5회). 지속 중 받는 물리 피해 -50%. |

이번 단계에는 이름·원화·전투 효과를 게임에 적용하지 않는다. 향후 적용 때도 내부 데이터 ID·능력 수치·범위·사거리·타이밍을 유지하고, 위 설명은 그 규칙에 입히는 시각적 콘셉트로 사용한다. 스킬의 표기 수치는 기본 데이터 기준이며 실제 전투의 층·위협 보정은 기존 규칙을 따른다.

## 전신·초상화·SD 기준

- 전신: 약 7~8등신의 성인 여성. 적당한 가슴 볼륨과 가는 허리, 도약에 익숙한 하체. 제비꼬리 쌍도와 등에 고정한 접이식 활의 주요 형태와 얼굴을 함께 읽히게 한다.
- 초상화: 전신과 같은 얼굴·머리색·눈색·복식·가슴 유형. 머리 장식과 주요 상징을 상반신 안에 배치한다.
- SD: 약 3등신의 같은 성인 캐릭터. 머리·주무기·세력색·D컵 중간형의 의상 윤곽을 단순화해 유지한다.
- 팔·손은 각각 두 개. 기본 전투 방향은 화면 오른쪽이며 적 진영의 반전은 향후 기존 렌더러를 따른다.
