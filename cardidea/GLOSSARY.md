# 용어 정리

카드 설계안과 게임 화면에 나오는 약어·용어. 수치 규칙은 현재 구현 기준 (DESIGN.md 2·3장, data/README.md "피해 적용 순서").

## 유닛 스탯

| 용어 | 풀이 | 의미 | 예 |
|---|---|---|---|
| **HP** | Hit Points, 체력 | 0이 되면 쓰러진다 | 방패병 650 |
| **ATK** | Attack, 공격력 | 기본 공격 1회 피해. 스킬의 "ATK 150%"는 이 값의 1.5배 | 투기장 신병 52 |
| **AS** | Attack Speed, 공격 속도 | 초당 공격 횟수. AS +20%면 0.75 → 0.9 | 그림자 단검 0.80 |
| **RNG** | Range, 사거리 | 공격이 닿는 칸 수. 1 = 근접(붙어서 공격), 3 이상 = 원거리 | 군단 석궁병 4 |
| **ARM** | Armor, 방어력 | **물리 피해**를 줄인다. 받는 피해 × 100 / (100 + ARM) | ARM 50이면 물리 피해 ×0.67 (33% 감소) |
| **RES** | Resistance, 마법 저항 | **마법 피해**를 줄인다. 공식은 ARM과 같음 | RES 100이면 마법 피해 ×0.5 |
| **MANA** | 마나 | 가득 차면 스킬을 쓰고 0으로 돌아간다. 공격 1회 +10, 맞으면 받은 피해의 1%(1회 최대 +15) | 방패병 최대 80 |

- **ARM·RES 감소**(예: "ARM −40")는 이 공식의 값을 낮춰 아군 피해가 더 들어가게 한다.
- **방어 무시 n%**: 계산할 때 대상의 ARM/RES를 n%만큼 덜 쳐 준다.

## 피해 종류

| 용어 | 의미 |
|---|---|
| **물리 피해** | ARM으로 줄어든다. 대부분의 기본 공격 |
| **마법 피해** | RES로 줄어든다. 주문 카드·화상 대부분 |
| **고정 피해** | ATK와 무관하게 정해진 수치(카드 피해는 모두 고정 수치). 이후 ARM/RES는 똑같이 적용 |
| **화상** | 지속 시간 동안 1초마다 마법 피해. 다시 걸면 시간 갱신, 초당 피해는 큰 쪽 (겹치지 않음) |
| **치명타** | 확률로 피해 ×1.5 (암살자 특성). 기본 공격·ATK 비례 스킬만 해당 |
| **반사** | 받은 피해의 n%를 공격자에게 되돌림 (방어 무시) |
| **생명력 흡수** | 입힌 실제 HP 피해의 n%만큼 회복 |
| **과열** | 전투 30초 이후 모든 피해가 1초마다 +10%. 90초가 되면 무승부 |

## 방어·회복

| 용어 | 의미 |
|---|---|
| **보호막** | HP보다 먼저 피해를 흡수. "최대 HP 15% 보호막"은 최대 HP의 15%만큼 |
| **받는 피해 −n%** | 방어 계산 전에 피해를 곱으로 줄임 (여러 개면 곱연산) |
| **HP 1 밑으로 안 내려감** | 지속 동안 쓰러지지 않음 (최후의 저항) |
| **재생** | 지속 동안 1초마다 최대 HP의 n% 회복 |

## 상태 이상 (적에게)

| 용어 | 의미 |
|---|---|
| **기절** | 이동·공격·스킬 모두 불가 |
| **침묵** | 스킬만 불가 (이동·공격 가능, 마나는 계속 참) |
| **속박** | 이동만 불가 (공격·스킬 가능) |
| **도발** | 반경 안의 적이 도발한 유닛을 우선 공격 |
| **우선 공격(집중)** | 아군이 지정한 적을 먼저 노림 |
| **해로운 상태 제거(정화)** | 기절·침묵·속박·화상·도발당함·피해 증가·스탯 감소를 지움 |

## 카드·전투 자원

| 용어 | 의미 |
|---|---|
| **CP** | Command Points, 지휘력. 카드 비용으로 쓴다. 전투 시작 2, 4초마다 +1, 최대 6, 전투마다 초기화. 준비 단계에는 작전 카드용 CP 2를 따로 준다 |
| **지휘관 HP** | 런 생명력. 전투에서 지거나 카드 대가(HP n)로 줄고, 0이면 런 종료 |
| **궁극기 게이지** | 0→100. 카드를 쓰면 +15, 아군이 쓰러지면 +25. 가득 차면 전투당 1회 궁극기 |
| **손패 / 드로우** | 손에 든 카드 / 덱에서 카드를 뽑기 |
| **준비 단계** | 전투 시작 전. 유닛 배치·상점·작전 카드를 쓰는 시간 |

## 카드 타입

| 타입 | 언제 | 비고 |
|---|---|---|
| **작전** | 준비 단계만 | 대부분 "이번 전투 동안" 효과 |
| **명령** | 전투 중 | 버프·회복·CP·드로우 등 |
| **주문** | 전투 중 | 적·칸·3×3 범위를 지정하는 공격·제어 |
| **장비** | 준비 단계 | 아군 1명에 영구 장착, 카드는 덱에서 빠짐 (덱 압축) |
| **저주** | 사용 불가 또는 자동 발동 | 손패 자리를 차지하는 패널티 |

## 카드 키워드

| 키워드 | 의미 |
|---|---|
| **소모** | 쓰면 이번 런에서 사라진다 |
| **보존** | 전투가 끝나도 손패에 남는다 |
| **연쇄** | 이번 전투에서 앞서 카드를 썼으면 추가 효과 (비용 감소 포함) |
| **징집** | 전투 중 임시 유닛 소환, 전투가 끝나면 사라짐 |
| **공명 [특성]** | 그 특성이 아군에서 켜져 있으면 추가 효과 |
| **HP n** | 지휘관 HP n을 대가로 낸다 (사용 후 HP 1 이상일 때만) |
| **전투당 n회** | 같은 카드는 한 전투에 n번까지만 |
| **강화(+)** | 야영지 단련·이벤트로 강화한 버전 |

## 보드·위치

| 용어 | 의미 |
|---|---|
| **전열 / 후열** | 보드 가운데에 가까운 열 / 먼 열 |
| **근접 / 원거리** | 사거리 1 / 사거리 2 이상 |
| **3×3** | 지정한 칸을 중심으로 한 9칸 |
| **반경 n칸** | 가로·세로·대각선 모두 n칸 안 |

## 특성·성급

| 용어 | 의미 |
|---|---|
| **기원** | 강철군단·잿불·심연·숲의 맹약 (유닛 출신) |
| **직업** | 수호자·검투사·사수·주술사·암살자 (유닛 역할) |
| **특성 단계** | 같은 기원/직업 유닛 수 2/4/6에서 1/2/3단계 효과 |
| **성급 (1·2·3성)** | 같은 유닛 3기 합성 → 2성(스탯 ×1.8), 2성 3기 → 3성(×3.2, 스킬 강화) |
| **등급 (1~5)** | 유닛 희귀도·가격(골드) |
