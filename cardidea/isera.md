# 이세라 전용 카드 후보

**불꽃 마도사 이세라** — 잿불·주술사, 유닛이 약한 대신 카드로 전투를 끝낸다. 패시브: 주문 피해 +25%, 시작 CP +1. 궁극기 대분화(운석 3곳).
표 읽는 법과 🔧 번호는 [README.md](README.md). 전용 카드는 이세라로 플레이할 때만 보상·상점에 나온다. 아래 피해 수치는 패시브 +25% 적용 **전** 값이다.

- **고유 시작 카드 (제안)**: 불씨 화살 (1CP 주문, 적 1명 마법 80 + 화상 초당 20 3초, 소모) — 지금 공용 카드를 이세라 고유로 전환
- **빌드 축**
  - **A. 주문 폭격**: 단일·범위 주문 피해로 직접 처치
  - **B. 화상 확산**: 화상을 넓게 깔고 화상 대상에게 추가 피해 (잿불 공명)
  - **C. 마나·순환**: 드로우·CP·마나로 주술사 스킬과 카드를 계속 돌린다 (주술사 공명)
